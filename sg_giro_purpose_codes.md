## Notes for coding agents

- Treat `purpose_code` as a string, not a number.
- Codes are uppercase and 4 characters long.
- Descriptions are copied from the source PDF. Do not silently correct spelling unless your application has a separate display-normalization layer.
- Validate user input case-insensitively if needed, then store the normalized uppercase code.
